# Vitrea

A browser real-time strategy game on a glass frontier: three factions, a
five-mission campaign, skirmish against the computer, and 1v1 online play.

**Play:** https://stevejleon86-oss.github.io/vitrea-play/

To play a friend online, one of you clicks **Create game** on the start menu and
sends the 5-character code; the other types it in and clicks **Join**. Works best
with both players on Chrome or Edge.

This repository holds only the built game, published with GitHub Pages.
